# Coverage Matrix: Research & Academic

- **Sub-domain**: literature review, research question framing, methodology design, citation/paraphrase checking, peer review response, grant proposal writing, abstract writing, data/results interpretation
- **Persona**: undergrad, PhD student, postdoc, PI/advisor
- **JTBD stage**: plan → draft → critique → synthesize
- **Output format**: outline, table, annotated draft, response letter

## Shipped

1. [Literature Review Synthesis Table Builder](../../en/research-and-academic/literature-review-synthesis-table-builder.md) — literature review / synthesize / PhD student.
2. [Research Question Sharpener](../../en/research-and-academic/research-question-sharpener.md) — research question framing / plan.
3. [Reviewer Comment Response Drafter](../../en/research-and-academic/reviewer-comment-response-drafter.md) — peer review response / draft / postdoc.
4. [Abstract Compressor to Word Limit](../../en/research-and-academic/abstract-compressor-to-word-limit.md) — abstract writing / edit.
5. `methodology-section-critique` — methodology design / critique / advanced — checks a methods section for unjustified sample size, unaddressed confounds, and construct-operationalization gaps.
6. `paraphrase-vs-plagiarism-checker` — citation checking / critique / intermediate — checks a paraphrase against its source for patchwriting, retained phrasing, and meaning drift, beyond what exact-match plagiarism tools catch.
7. `advisor-feedback-translator` — peer review response / explain / intermediate — unpacks terse advisor feedback into concrete revision actions, presenting candidate readings where genuinely ambiguous rather than guessing.
8. `grant-proposal-aims-page-tightener` — grant proposal / optimize-refactor / advanced — checks aim independence, significance/innovation framing, and calibrates ambition-vs-feasibility on a specific-aims page.
9. `results-section-plain-language-summary` — data interpretation / explain / intermediate — translates technical statistical results into lay language without overclaiming, distinct from `abstract-compressor-to-word-limit`'s length-compression scope.
10. `related-work-gap-finder` — literature review / analyze / advanced — flags under-covered adjacent research angles given a paper's claimed contribution, explicitly forbidden from fabricating specific citations.
11. `conference-talk-outline-from-a-paper` — synthesize / draft / intermediate — reorders a paper's content into oral-presentation logic for a time-limited talk, identifying the result to anchor around.
12. `statistical-reporting-style-checker` — methodology / review-critique / intermediate — checks reported statistics against a target journal's style guide (notation, required effect sizes/CIs, p-value formatting).

2. **Limitations Section Completeness Checker** — methodology / critique — checks a limitations section against the study's actual design gaps, flagging omitted limitations a reviewer would raise.
3. **Figure/Table Caption Self-Sufficiency Checker** — data interpretation / critique — checks whether figures/tables are interpretable without reading the surrounding text, per most journals' standards.
4. **Thesis Chapter Transition Smoother** — synthesize / optimize-refactor — drafts connective framing between thesis chapters so they read as one argument, not stapled-together papers.
5. **Interview Protocol Bias Auditor** — methodology / critique — reviews a qualitative interview protocol for leading questions and framing that could bias responses.
6. **Co-Author Contribution Statement Drafter** — document / draft — drafts a CRediT-style contribution statement from a description of who did what.
7. **Null Result Framing Advisor** — data interpretation / plan — helps frame a null/non-significant result's contribution honestly, without either overselling or burying it.
8. **Dissertation Defense Question Anticipator** — assess / plan — generates likely committee questions given a dissertation's actual claims and methodology, prioritized by how exposed each claim is.
9. **Systematic Review PRISMA Compliance Checker** — literature review / critique — checks a systematic review draft against PRISMA reporting checklist items.
10. **Research Data Management Plan Drafter** — document / draft — drafts a funder-required data management plan section from a study's actual data types and sharing constraints.
11. **Cross-Disciplinary Jargon Translator for Reviewers** — explain / draft — translates field-specific jargon in a manuscript for a reviewer likely to be from an adjacent but distinct discipline.
12. **Replication Study Pre-Registration Drafter** — research design / draft — drafts a pre-registration document for a planned replication, specifying what would count as successful vs. failed replication in advance.
