# Coverage Matrix: Productivity & Personal

- **Sub-domain**: task/project planning, meeting management, decision-making, habit building, journaling/reflection, email/inbox triage, time blocking, personal finance planning, travel planning
- **Persona**: individual contributor, manager, freelancer, student
- **JTBD stage**: plan → triage → reflect → decide → review
- **Output format**: plan/schedule, checklist, script, reflection prompt
