## Description
Rewrites stiff, textbook-style e-learning narration to sound like natural spoken instruction — contractions, varied sentence length, direct address — while preserving every piece of actual instructional content and never softening precision on anything that must stay exact (a number, a defined term, a safety-critical step).

## When to use it
- Your e-learning narration script was written like a textbook (long sentences, no contractions, passive voice) and sounds robotic or stiff when read aloud or fed through TTS.
- You're converting existing written training material into a narration script and need it to sound like a person talking, not a document being read verbatim.
- You want a naturalized draft but are worried about accidentally losing precision on a critical detail during the rewrite — this prompt's discipline exists specifically to prevent that.

## The Prompt

```
You rewrite e-learning narration to sound naturally spoken rather than written like a textbook — you do not lose or soften any instructional content, and you do not touch anything flagged as precision-critical.

Original script: {{ORIGINAL_SCRIPT}}
Terms/numbers/steps that must stay exactly as written (safety-critical, defined terminology, exact figures): {{MUST_STAY_EXACT}}
Target listener/context: {{AUDIENCE_CONTEXT}}

Instructions:
1. Convert to natural spoken patterns: add contractions where a person would naturally use them ("don't" not "do not," "you'll" not "you will"), break up long compound-complex sentences into the shorter, more varied lengths natural speech actually uses, and shift passive constructions to active where doing so doesn't change the meaning ("the system generates a report" rather than "a report is generated by the system").
2. Add direct address where it makes the instruction feel like it's being spoken to the listener rather than describing a process abstractly — "you'll click Submit" rather than "the user clicks Submit," unless {{AUDIENCE_CONTEXT}} specifically calls for third-person/formal address.
3. Before touching any sentence, check it against {{MUST_STAY_EXACT}} — if a sentence contains a listed term, number, or step, naturalize the surrounding language but leave the flagged content itself completely unchanged, character for character.
4. Do not naturalize away actual precision even outside {{MUST_STAY_EXACT}} — a naturalized sentence should convey exactly the same instructional content as the original, not a looser paraphrase that happens to sound more casual; "naturalizing" is about delivery style, not simplifying or summarizing the content.
5. Preserve the original structure/sequence of instructional steps — reordering for a more "natural" narrative flow risks changing the actual order a learner needs to follow, which is a functional error, not a stylistic one.
6. Flag any place where naturalizing genuinely created ambiguity that wasn't in the stiffer original (rare, but a very short colloquial phrasing can sometimes lose a precise qualifier the formal version had) — don't silently accept an ambiguity introduced by the rewrite.

Output format: the naturalized script, with any content from {{MUST_STAY_EXACT}} visually unchanged and easy to spot (e.g. left exactly as given). Follow with a short list of anything flagged in step 6, or "none" if nothing needed flagging.
```

## Variables
- `{{ORIGINAL_SCRIPT}}` — the stiff/textbook-style narration script to naturalize. Required.
- `{{MUST_STAY_EXACT}}` — specific terms, numbers, or steps that must not be reworded under any circumstances. Required — without an explicit list, the naturalization pass has no way to know what's safe to touch versus precision-critical.
- `{{AUDIENCE_CONTEXT}}` — who the learner is and the tone appropriate for them (a casual internal onboarding vs. a formal compliance training). Required — this affects how far to push toward casual/conversational phrasing.

## Example
**Input:** `{{ORIGINAL_SCRIPT}}` = "The user must ensure that the safety valve is set to exactly 4.5 PSI prior to initiating the startup sequence. Failure to do so may result in equipment damage." `{{MUST_STAY_EXACT}}` = "4.5 PSI; 'safety valve'; 'startup sequence'" `{{AUDIENCE_CONTEXT}}` = "New warehouse equipment operators, informal but serious onboarding training"

**Output (excerpt):**
```
Before you start the startup sequence, make sure the safety valve is set to exactly 4.5 PSI. If it's not, you could damage the equipment.

Flagged: none — "safety valve," "startup sequence," and "4.5 PSI" preserved exactly as given; the surrounding language was naturalized (contractions, active voice, direct address) without changing the actual instruction or its sequence.
```

## Tips & Variations
- Pair with `voiceover-script-with-delivery-direction-annotations` (voice-and-audio, already shipped) after naturalizing — that prompt adds pacing/emphasis annotation once the script's actual wording is finalized, since annotating a script that's about to be reworded wastes the annotation pass.
- For a very long training module, naturalize in sections rather than all at once and spot-check that {{MUST_STAY_EXACT}} terms survived unchanged across the full document — the discipline can slip on a long single pass even with clear instructions, so a section-by-section check catches drift.
- If most of a script needs almost no naturalization (it was already written conversationally), that's a useful signal the source material may already be closer to narration-ready than expected — don't force stylistic changes onto already-natural sentences just to seem thorough.
