| id | Назва | Складність | Опис |
|---|---|---|---|
| [`cold-email-sequence-drafter`](./cold-email-sequence-drafter.md) | Укладач послідовності холодних листів | intermediate | Складає послідовність холодних листів для аутріч (перший лист плюс фоллоу-апи) під конкретну пропозицію й аудиторію — інструмент для структури послідовності й написання чернетки, відмінний від генератора одного листа: він планує зміну кута подачі між листами, а не пише лише одне повідомлення. |
| [`non-native-english-polish-pass`](./non-native-english-polish-pass.md) | Шліфування англійської для не носіїв мови | beginner | Виправляє фразування, ідіоми й граматику в англомовному тексті, написаному не носієм мови, не стираючи голос автора і не надформалізовуючи текст — відмінний від «ruthless-line-editor» (працює з довжиною, не коректністю) і «tone-adapter» (змінює регістр уже коректної англійської). Для чернетки, яка зрозуміла, але явно звучить не як текст носія мови в місцях, які автор хоче згладити. |
| [`outline-to-draft-blog-expander`](./outline-to-draft-blog-expander.md) | Розгортач плану в чернетку статті | intermediate | Розгортає план у вигляді пунктів на повну чернетку статті у вказаному голосі — інструмент для написання чернетки, для соло-автора чи контент-команди, які вже знають, що хочуть сказати, і потребують перетворення цього на читабельний текст, а не генератор ідей, що вирішує, про що має бути стаття. |
| [`ruthless-line-editor`](./ruthless-line-editor.md) | Безжальний редактор рядків | beginner | Скорочує кількість слів у тексті на цільовий відсоток, зберігаючи зміст і голос — механічний прохід стиснення, відмінний від «tone-adapter» (змінює регістр, не довжину) і «non-native-english-polish-pass» (виправляє фразування/ідіоми, не насамперед довжину). Для чернетки, яка каже правильну річ, але забагатьма словами. |
| [`tone-adapter`](./tone-adapter.md) | Адаптер тону | intermediate | Переписує текст у вказаний тон/голос бренду, зберігаючи зміст незмінним — зміна регістру, відмінна від «ruthless-line-editor» (змінює довжину, не регістр) і «non-native-english-polish-pass» (виправляє помилки фразування, не голос). Для контенту, який каже правильну річ, але звучить не там, куди йде. |
| [`ux-microcopy-reviewer`](./ux-microcopy-reviewer.md) | Рев'ювер UX-мікротекстів | intermediate | Аудитує мікротексти інтерфейсу — підписи кнопок, повідомлення про помилки, порожні стани, підказки, діалоги підтвердження — на ясність, послідовність тону й дієвість, і пропонує конкретне перефразування для кожної знахідки. Інструмент критики й виправлення для тексту інтерфейсу, а не загальний генератор копірайту. |
