## Опис
Складає шаблони відповідей модератора для забезпечення дотримання реальних правил спільноти проти поширених типів порушень — спам, переслідування, офтопік-промоція, дезінформація — чіткі щодо того, яке конкретно правило порушено і що буде далі, тверді, але не зайво ворожі, і відкалібровані по-різному для першого проти повторного порушення.

## Коли використовувати
- Налаштовуєш модерацію для нової спільноти й потрібен стартовий набір шаблонів відповідей для дотримання правил замість імпровізації тону й формулювання на льоту для кожного порушення.
- Кілька модераторів застосовують ті самі правила непослідовно (різний тон, різна чіткість щодо того, що буде далі), і потрібен спільний набір шаблонів для стандартизації відповідей.
- Хочеш перевірити чернеткову відповідь модератора проти реально порушеного правила, оскільки повідомлення про дотримання правил, що не називає конкретне правило, може здатись довільним отримувачу.

## Промпт

```
Ти складаєш шаблони відповідей модератора для забезпечення дотримання реальних правил спільноти. Кожен шаблон має називати конкретне порушене правило й чітко вказувати, що буде далі — розмита мова забезпечення дотримання правил, що не пояснює «чому», читається як довільна й посилює опір, навіть коли сама модераційна дія правильна.

Правила спільноти/платформи (реальні правила): {{GUIDELINES}}
Типи порушень для покриття: {{VIOLATION_TYPES}}
Платформа: {{PLATFORM}}

Інструкції:
1. Для кожного типу порушення в {{VIOLATION_TYPES}} склади окремо шаблон першого порушення й шаблон повторного порушення — повторне порушення виправдовує інший тон (менше презумпції доброї волі, чіткіша заява ескалуючого наслідку), ніж перший випадок, який часто краще обробляти як припущення незнайомства з правилами, а не недобросовісності.
2. Назви конкретне правило з {{GUIDELINES}}, що забезпечується, у кожному шаблоні — цитуй чи близько перефразуй реальний текст правила, не загальне «це порушує наші стандарти спільноти», що не каже людині, що вона реально зробила.
3. Чітко вкажи конкретний наслідок/наступний крок: контент видалено, попередження зафіксовано, тимчасове обмеження чи ескалація до бану — залежно від того, що доречно для типу порушення й кількості порушень, і переконайся, що заявлений наслідок — той, який команда модерації реально й послідовно може забезпечити.
4. Тримай тон твердим, але не ворожим, навіть для серйозних порушень (переслідування, дезінформація) — шаблон, що зайво агресивний, схильний ескалувати взаємодію, а не закривати її, тоді як шаблон, надто м'який для серйозного порушення, применшує, наскільки серйозно спільнота це сприймає; калібруй конкретно під реальну серйозність порушення.
5. Для типів порушень, де добросовісні помилки поширені (офтопік-промоція, нерозуміння нюансованого правила), включи короткий шлях для людини поставити уточнювальне питання чи оскаржити, а не суто одностороннє повідомлення — це зменшує повторне тертя від справжньої розгубленості проти навмисного порушення правил.
6. Для типів порушень, що рідко бувають добросовісними помилками (спам, переслідування, навмисна дезінформація), шаблон може бути прямішим і не потребує надмірного пояснення чи надмірних вибачень за модераційну дію.

Формат виводу: Markdown, одна секція на тип порушення, кожна з шаблоном «Перше порушення» й «Повторне порушення». Додай однорядкову примітку на шаблон про те, що конкретно відрізняється між двома версіями.
```

## Змінні
- `{{GUIDELINES}}` — реальні заявлені правила/настанови спільноти. Обов'язково — шаблони мають посилатись на реальні правила, не загальні.
- `{{VIOLATION_TYPES}}` — конкретні типи порушень, для яких скласти шаблони (спам, переслідування, офтопік-промоція, дезінформація чи інші, специфічні для цієї спільноти). Обов'язково.
- `{{PLATFORM}}` — платформа, оскільки норми тону й доступні модераційні дії (заглушення, тимчасовий бан, видалення контенту) різняться за платформою. Обов'язково.

## Приклад
**Вхід:** `{{GUIDELINES}}` = «Правило 3: Жодного промоційного контенту чи посилань поза призначеним каналом #self-promo.» `{{VIOLATION_TYPES}}` = «Офтопік-промоція» `{{PLATFORM}}` = «Discord»

**Вихід (уривок):**
```
### Офтопік-промоція

**Перше порушення:**
«Привіт, [ім'я] — я видалив твоє повідомлення в #general, оскільки це промоційний контент, який за Правилом 3 має йти в #self-promo замість основних каналів. Нічого страшного, таке буває — не соромся перепостити там! Дай знати, якщо є питання про те, що рахується.»

Примітка: Припускає добру волю (могли не знати про виділений канал), дає чіткий шлях реально поділитись контентом правильно, а не просто видаляє без вирішення, і пропонує відкритість для уточнювального питання.

**Повторне порушення:**
«Привіт, [ім'я] — це вже другий раз, коли промоційний контент постять поза #self-promo (Правило 3). Я знову видалив. Оскільки це повтор, подальші пости поза #self-promo можуть призвести до тимчасового заглушення. Будь ласка, дотримуйся #self-promo для всього промоційного надалі.»

Примітка: Явно заявляє повтор (знімає рамку презумпції доброї волі), називає конкретний наслідок ескалації на наступний раз, і опускає пом'якшення «нічого страшного», оскільки припущення доброї волі слабше при другому випадку.
```

## Поради та варіації
- Поєднуй із «Драфтером заяви кризового реагування» (social-media, вже випущений), якщо сама модераційна дія стає публічно суперечливою (високопрофільний користувач публічно оскаржує рішення про модерацію) — той промпт побудований для публічних кризових заяв, іншої й вищоставкової ситуації, ніж рутинне індивідуальне повідомлення про дотримання правил.
- Переглядай і оновлюй ці шаблони щоразу, коли {{GUIDELINES}} змінюються — шаблон, що цитує застаріле правило, підриває пояснення «чому», яке цей промпт покликаний надавати, і модератори, що використовують застарілий шаблон, можуть створити реальну розгубленість щодо того, яке правило реально чинне.
- Для великої команди модерації зберігай згенеровані шаблони в спільному довідковому документі, а не дозволяй кожному модератору імпровізувати незалежно — перевага послідовності тримається лише якщо всі реально використовують ті самі базові шаблони, адаптовані під ситуацію, а не написані з нуля щоразу.
