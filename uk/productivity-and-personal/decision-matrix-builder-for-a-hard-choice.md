## Опис
Складає зважену матрицю рішень (варіанти × критерії, зважені й оцінені) для складного особистого чи професійного вибору — структурує компроміси, які ти вже відчуваєш, але не сформулював явно, а не каже, що вирішувати.

## Коли використовувати
- Ти застряг між варіантами й ходиш по колу, бо компроміси в голові неструктуровані, а не викладені чітко.
- Хочеш перевірити, чи інтуїтивний вибір реально витримує, коли важливі для тебе критерії стають явними й зваженими.
- Потрібно пояснити рішення комусь іншому (партнеру, менеджеру, правлінню), і хочеш структурований артефакт, не просто «в мене таке відчуття».

## Промпт

```
Ти складаєш зважену матрицю рішень для складного вибору. Ти структуруєш власні заявлені критерії й чесні оцінки варіантів того, хто вирішує — ти не вирішуєш за нього і не додаєш критерії, які він не згадував, ніби вони були надані.

Рішення: {{DECISION}}
Варіанти: {{OPTIONS}}
Критерії, що мають значення (якщо відомо): {{CRITERIA}}

Інструкції:
1. Якщо {{CRITERIA}} не надано чи здається неповним, запитай, що реально важливо для цього рішення, перш ніж будувати матрицю — матриця, побудована на вгаданих критеріях, дає впевнено виглядаючу, але необґрунтовану відповідь.
2. Для кожного критерію попроси того, хто вирішує, зважити його відносну важливість (чи прийми ваги, якщо вже надані) — не припускай, що всі критерії однаково важливі, оскільки це рідко правда й сплющує реальний компроміс.
3. Оціни кожен варіант проти кожного критерію за послідовною шкалою (напр., 1-5), і попроси обґрунтування для неочевидних оцінок, а не мовчки їх признач — якщо ти виводиш оцінку, а не отримуєш її, скажи це явно (`[ВИВЕДЕНО: ...]`).
4. Розрахуй зважені суми, але явно сформулюй результат як один вхід у рішення, не фінальний вердикт — матриця рішень виявляє структуру компромісу; вона не переважує судження щодо факторів, що опираються квантифікації (інтуїція, цінності, толерантність до ризику, не охоплені критеріями).
5. Після сум перевір на близький результат: якщо два верхні варіанти в межах невеликого відриву, скажи це явно й познач, який критерій, якби мав іншу вагу, перевернув би результат — це часто корисніше за сирий рейтинг, бо показує, на чому реально тримається рішення.
6. Якщо критерій сформульований так, що насправді означає уникнення рішення (напр., «який безпечніший» без визначення, що таке безпека тут), попроси конкретизувати перед оцінюванням, а не оцінюй проти розпливчастого критерію.

Формат виводу: таблиця Markdown (рядки = варіанти, стовпці = критерії + зважена сума), далі секція `### На чому це тримається` для будь-якого близького результату.
```

## Змінні
- `{{DECISION}}` — однорядковий опис рішення, що приймається. Обов'язково.
- `{{OPTIONS}}` — конкретні варіанти, що зважуються. Обов'язково.
- `{{CRITERIA}}` — що має значення для цього вибору, якщо вже відомо. Необов'язково — промпт запитає, якщо це відсутнє чи тонке.

## Приклад
**Вхід:** `{{DECISION}}` = «Чи прийняти нову пропозицію роботи, чи залишитись у поточній компанії» `{{OPTIONS}}` = «Залишитись у поточній компанії; Прийняти нову пропозицію» `{{CRITERIA}}` = «Компенсація (вага: висока), можливість зростання (вага: висока), відповідність команді/культурі (вага: середня), дорога на роботу (вага: низька)»

**Вихід (уривок):**
```
| Критерій (вага) | Залишитись | Нова пропозиція |
|---|---|---|
| Компенсація (висока) | 3/5 — поточна компенсація нормальна, але не зростала 2 роки | 5/5 — нова пропозиція — значне підвищення |
| Можливість зростання (висока) | 2/5 — [ВИВЕДЕНО: ти згадував відчуття застрягання в попередній розмові — підтверди, чи це точно] | 4/5 — нова роль має чіткіший шлях до більшого обсягу |
| Відповідність команді/культурі (середня) | 5/5 — відома, перевірена команда | 2/5 — невідомо, зустрів лише 3 людей на співбесідах |
| Дорога на роботу (низька) | 4/5 | 3/5 |
| **Зважена сума** | ... | ... |

### На чому це тримається
Два варіанти близькі після зважування. Найбільший поворотний фактор — Відповідність команді/культурі — ти оцінюєш нову пропозицію низько там саме тому, що це невідомо, не тому, що маєш негативний сигнал. Якщо ця оцінка відображає справжню невизначеність, а не реальний тривожний сигнал, можливо, варто оцінити її нейтрально, а не низько, поки не буде більше інформації (напр., розмова з майбутнім колегою), що суттєво зсунуло б суму в бік нової пропозиції.
```

## Поради та варіації
- Не трактуй зважену суму як фінальну відповідь, якщо вона сильно суперечить інтуїції — сама ця суперечність корисна інформація, або критерій неправильно зважений, або щось, не охоплене матрицею (цінності, толерантність до ризику), реально керує справжньою перевагою.
- Для рішення з більш ніж жменькою критеріїв опирайся спокусі додати кожен можливий фактор — матриця, розмита по 15 критеріях подібної ваги, зазвичай дає розмиту суму, яка реально нічого не прояснює; тримай 4-6 критеріїв, що реально диференціюють варіанти.
- Для оборотного, низькоризикового рішення такий рівень структури часто зайвий — цей промпт найкорисніший для справді складних, високоризикових чи важко оборотних виборів, де зусилля структурування виправдані.
