## Опис
Формує базову специфікацію стилю стікера — опис маскота, художній стиль, обробку контуру/рамки та палітру — а також серію промптів-варіантів під конкретні вирази обличчя для невеликого, візуально консистентного набору чат-стікерів чи емодзі. Це емодзі-масштабний аналог «Генератора промптів для набору ізометричних іконок»: та сама дисципліна «база + варіант», застосована до виразів одного повторюваного маскота у форматі вирізного стікера, а не до набору непов'язаних плоских чи 3D-іконок.

## Коли використовувати
- Потрібен невеликий набір стікерів чи емодзі (приблизно 6-12 штук) для месенджера, Discord-сервера чи брендового чат-паку з одним маскотом у різних виразах/реакціях, і хочеш, щоб вони виглядали цілісним набором, а не окремо згенерованими фрагментами.
- Уже згенеровано кілька стікерів, і вони не збігаються (різна товщина контуру, різні пропорції, різна насиченість кольору), і потрібен жорсткіший базовий промпт, щоб вирівняти решту набору.
- Тестуєш візуальний напрямок стікер-паку перед замовленням фінального векторного чи ілюстраторського проходу.


## Змінні
- `{{MASCOT_BASE_DESCRIPTION}}` — вичерпний, фіксований опис незмінних візуальних рис маскота: вид/форма, кольори, відмінні риси (напр., «круглий помаранчевий маскот-лисеня, велика голова, маленьке тіло, біла пляма на животі, два маленьких загострених вуха»). Обов'язково — використовуй цей текст ідентично для кожного стікера набору; навіть невеликі зміни формулювання між стікерами — поширена причина дрейфу.
- `{{ART_STYLE}}` — підхід до рендерингу, ідентичний для всього набору (напр., «плоска векторна ілюстрація, мінімальне затінення», «м'який 2D-мультиплікаційний стиль із тонким градієнтом»). Обов'язково.
- `{{OUTLINE_AND_BORDER}}` — специфічна для стікера обробка формату (напр., «жирний чорний контур 4px, товста біла вирізна рамка стікера навколо всієї форми»). Обов'язково — саме це змушує набір читатися як чат/месенджер-стікери, а не звичайні ілюстрації персонажа.
- `{{COLOR_PALETTE}}` — конкретна, названа палітра, що повторюється в усьому наборі (напр., «палітра з помаранчевого, білого й вугільно-сірого лайнворку»), не розмите «кольоровий». Обов'язково.
- `{{EXPRESSION_OR_REACTION}}` — єдине, що змінюється для кожного стікера (напр., «сміється із заплющеними очима, сльози радості», «шокований, широко розплющені очі, руки на щоках», «махає рукою на привітання, одна лапа піднята»). Обов'язково.
- `{{ASPECT_RATIO}}` — ідентичне для всього набору, зазвичай квадратне (1:1) для стікерів і емодзі. Обов'язково.

## Поради та варіації
- Поєднуй із «Генератором промптів для набору ізометричних іконок» (creative-and-visual, вже випущений) для тієї самої дисципліни «база + варіант», застосованої до непов'язаних UI/продуктових іконок замість виразів одного маскота — використовуй той промпт для системи іконок на кшталт налаштувань/папки/графіка, цей — для чат-стікерпаку, побудованого навколо одного повторюваного персонажа.
- Для набору емодзі без маскота (напр., тематичний набір погоди чи їжі без повторюваного персонажа) заміни `{{MASCOT_BASE_DESCRIPTION}}` на спільний опис стилю категорії об'єктів і трактуй `{{EXPRESSION_OR_REACTION}}` як об'єкт, що змінюється, — та сама структура «базовий стиль + варіант» усе одно працює.
- Якщо набір має працювати як реальні платформні стікери чи емодзі (Telegram, Discord, Slack), перевір точний потрібний розмір полотна й правила прозорості цієї платформи перед фіналізацією — `{{OUTLINE_AND_BORDER}}` лише наближує вигляд вирізного стікера, а для справжнього експорту з прозорим фоном зазвичай усе одно потрібен наступний прохід видалення фону.
