## Опис
Складає базовий опис персонажа плюс серію варіантних промптів (різні пози/вирази), спроєктованих залишатись візуально послідовними між генераціями — вирішує основну складність AI-генерації зображень для роботи з персонажами: отримати «того самого» персонажа на кількох зображеннях, а не просто одне хороше зображення.

## Коли використовувати
- Ти інді-розробник ігор чи ілюстратор, кому потрібен той самий персонаж у кількох позах/виразах для референс-листа, коміксових панелей чи ігрових ассетів.
- Твій згенерований персонаж постійно змінюється в зовнішньому вигляді (інша форма обличчя, інші деталі вбрання) між окремими генераціями, і потрібна дисциплінованіша структура промпту, щоб зменшити цей дрейф.
- Хочеш задокументований базовий опис, який можна повторно використовувати й передавати (колезі чи собі через кілька тижнів), а не реконструювати візуальну ідентичність персонажа з пам'яті щоразу.

## Промпт

```
[БАЗОВИЙ ОПИС ПЕРСОНАЖА — повторно використовуй дослівно в кожному варіанті]
{{CHARACTER_BASE_DESCRIPTION}}, {{ART_STYLE}}

[ВАРІАНТ — змінюй лише цей рядок на кожну генерацію]
{{POSE_OR_EXPRESSION}}, {{VARIANT_CONTEXT}}

Повний промпт на варіант: {{CHARACTER_BASE_DESCRIPTION}}, {{POSE_OR_EXPRESSION}}, {{VARIANT_CONTEXT}}, {{ART_STYLE}}, consistent character design, character reference sheet style --ar {{ASPECT_RATIO}}
```

## Змінні
- `{{CHARACTER_BASE_DESCRIPTION}}` — вичерпний, фіксований опис незмінних візуальних рис персонажа: форма обличчя, волосся (колір, стиль, довжина), точні деталі вбрання (кольори, матеріали, відмінні аксесуари), статура, будь-які унікальні ідентифікуючі риси (шрами, позначки). Обов'язково — цей точний текст має бути дослівно скопійований у кожен промпт варіанта в серії; навіть невеликі зміни формулювання між варіантами — поширена причина дрейфу.
- `{{ART_STYLE}}` — стиль рендерингу, ідентичний по всій серії (напр., «cel-shaded аніме стиль, чиста лінійна графіка», «живописна цифрова ілюстрація»). Обов'язково.
- `{{POSE_OR_EXPRESSION}}` — єдина річ, що змінюється на зображення (напр., «руки схрещені, впевнена посмішка», «поза бігу, рішучий вираз»). Обов'язково.
- `{{VARIANT_CONTEXT}}` — мінімальний контекст сцени/фону, якщо потрібно, простий і послідовний за стилем серед варіантів (напр., «однотонний білий фон» для референс-листа, чи послідовний стиль оточення для наративних панелей). Обов'язково.
- `{{ASPECT_RATIO}}` — ідентичне по всій серії, якщо кейс конкретно не потребує варіації. Обов'язково.

## Поради та варіації
- Навіть з ідентичним базовим описом більшість поточних інструментів генерації зображень не можуть гарантувати піксель-точну послідовність персонажа між окремими генераціями так, як це може спеціалізована функція послідовності персонажа (де платформа її підтримує, напр., референсні зображення персонажа) — цей підхід лише на промптах зменшує дрейф, але не усуває його; очікуй перегенерації й вибору найближчих збігів, а не ідеальної послідовності з першої спроби.
- Якщо конкретна платформа підтримує image-to-image чи функцію референсу персонажа/стилю (подача попередньо згенерованого зображення назад як референсу), поєднай це зі структурою цього промпту для суттєво кращої послідовності, ніж лише текстовий промпт.
- Зберігай точну копію тексту {{CHARACTER_BASE_DESCRIPTION}}, використаного для першої успішної генерації — повторне використання точного формулювання (не його перефразування) для майбутніх варіантів — те, що тримає персонажа впізнаваним у зростаючому наборі зображень із часом.
