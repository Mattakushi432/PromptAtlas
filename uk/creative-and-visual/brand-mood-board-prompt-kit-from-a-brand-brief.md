## Опис
Генерує невеликий набір справді різноманітних промптів зображень мудборду з брифу бренду — охоплюючи різні візуальні території (текстура/матеріал, лайфстайл-фотографія, абстрактний патерн, типографічний настрій), а не варіації кольору однієї ідеї — даючи маркетинговому дизайнеру реальний діапазон для реакції перед вибором напрямку бренду. На відміну від «Генератора напрямків концепції логотипу» (creative-and-visual, вже випущений), що генерує конкретні концепції знаку логотипу для вже звуженого рішення; цей промпт покриває ранішу, ширшу стадію дослідження настрою/текстури до того, як логотип узагалі на столі.

## Коли використовувати
- Починаєш візуальне дослідження бренду й хочеш справді різноманітний стартовий мудборд, а не п'ять зображень, що всі одна й та сама ідея з заміненим кольором.
- Перша спроба генерації мудборду повернулась візуально вузькою (кожне зображення — той самий фотографічний стиль, лише різні суб'єкти), і потрібні промпти, структуровані так, щоб реально розходитись по візуальній території, а не лише за змістом.
- Хочеш AI-згенеровану образність мудборду як напрямне натхнення для розмови з дизайнером чи клієнтом — не фінальні активи бренду (це генерує дослідну референсну образність, не готову до використання продукційну фотографію чи заміну ліцензованих стокових зображень).

## Промпт

```
[ОСНОВА БРЕНДУ — повторно використовуй в усіх чотирьох промптах]
{{BRAND_ADJECTIVES}}, {{TARGET_AUDIENCE}}, differentiated from {{COMPETITOR_VISUAL_CLICHE}}

[ТЕРИТОРІЯ 1 — Текстура/Матеріал]
close-up macro texture study, {{MATERIAL_DIRECTION}}, {{BRAND_ADJECTIVES}}, no text, abstract composition --ar 1:1

[ТЕРИТОРІЯ 2 — Лайфстайл-фотографія]
lifestyle photograph, {{LIFESTYLE_SCENE}}, {{BRAND_ADJECTIVES}}, natural lighting, candid moment, shot for {{TARGET_AUDIENCE}} --ar 4:5

[ТЕРИТОРІЯ 3 — Абстрактний патерн]
abstract pattern design, {{PATTERN_MOTIF}}, {{BRAND_ADJECTIVES}}, repeating geometric composition, flat design --ar 1:1

[ТЕРИТОРІЯ 4 — Типографічний настрій]
typography mood board, large expressive lettering, {{TYPOGRAPHY_MOOD}}, {{BRAND_ADJECTIVES}}, minimal composition, on textured paper background --ar 4:5
```

## Змінні
- `{{BRAND_ADJECTIVES}}` — 3-4 прикметники, що передають реальну особистість бренду (напр., «теплий, ремісничий, невибагливий» проти «елегантний, точний, технічний»). Обов'язково — повторно використані в усіх чотирьох промптах як наскрізна лінія, що робить чотири візуально різні зображення все ще одним дослідженням бренду.
- `{{TARGET_AUDIENCE}}` — для кого бренд, оскільки це формує, які лайфстайл-сцени й вибори матеріалів читаються як автентичні проти загальних. Обов'язково.
- `{{COMPETITOR_VISUAL_CLICHE}}` — конкретний візуальний патерн, поширений серед конкурентів, якого це дослідження має свідомо уникати (напр., «мінімалістичний біло-шавлієвий вигляд, який використовує кожен бренд догляду за шкірою»). Обов'язково — називання того, від чого диференціюватись, — те, що утримує мудборд від конвергенції до тієї самої території, що й усі інші в категорії.
- `{{MATERIAL_DIRECTION}}` — для Території 1: конкретна концепція матеріалу/текстури, прив'язана до бренду (напр., «сирий неглазурований керамограніт, натуральне лляне плетіння», «шліфований алюміній, матова гума»). Обов'язково для цього промпту.
- `{{LIFESTYLE_SCENE}}` — для Території 2: конкретна, реальна сцена, а не загальне «людина використовує продукт» (напр., «руки замішують тісто на посипаному борошном дерев'яному прилавку, ранкове світло»). Обов'язково для цього промпту.
- `{{PATTERN_MOTIF}}` — для Території 3: конкретне джерело форми/мотиву, прив'язане до концепції бренду, не загальний геометричний патерн (напр., «мотиви, похідні від ліній контурів топографічної карти» для аутдор-бренду). Обов'язково для цього промпту.
- `{{TYPOGRAPHY_MOOD}}` — для Території 4: характер літерних форм, що досліджується (напр., «жирний конденсований гротеск, високий контраст», «вільне експресивне рукописне письмо»). Обов'язково для цього промпту.

## Приклад
**Вхід:** `{{BRAND_ADJECTIVES}}` = «теплий, ремісничий, неквапливий» `{{TARGET_AUDIENCE}}` = «домашні кухарі, що цінують повільне, свідоме приготування над зручністю» `{{COMPETITOR_VISUAL_CLICHE}}` = «яскраво-білий мінімалістичний студійно-фотографічний вигляд, який використовує більшість брендів наборів для готування» `{{MATERIAL_DIRECTION}}` = «сирий неглазурований керамограніт, натуральний льон» `{{LIFESTYLE_SCENE}}` = «руки замішують тісто на посипаному борошном дерев'яному прилавку, м'яке ранкове світло з вікна» `{{PATTERN_MOTIF}}` = «мотиви, похідні від колосків пшениці й зернових текстур» `{{TYPOGRAPHY_MOOD}}` = «вільне експресивне рукописне письмо, злегка недосконале»

**Територія 1 — Текстура/Матеріал:**
```
close-up macro texture study, raw unglazed stoneware, natural linen, warm, artisanal, unhurried, no text, abstract composition --ar 1:1
```

**Територія 2 — Лайфстайл-фотографія:**
```
lifestyle photograph, hands kneading dough on a flour-dusted wooden counter, soft morning window light, warm, artisanal, unhurried, natural lighting, candid moment, shot for home cooks who value slow, intentional cooking over convenience --ar 4:5
```

**Територія 3 — Абстрактний патерн:**
```
abstract pattern design, motifs derived from wheat stalks and grain textures, warm, artisanal, unhurried, repeating geometric composition, flat design --ar 1:1
```

**Територія 4 — Типографічний настрій:**
```
typography mood board, large expressive lettering, loose expressive hand-lettering, slightly imperfect, warm, artisanal, unhurried, minimal composition, on textured paper background --ar 4:5
```

## Поради та варіації
- Якщо всі чотири території все ще відчуваються візуально схожими попри різні промпти, імовірна причина — {{BRAND_ADJECTIVES}} занадто загальні (прикметники, що могли б описати половину категорії), а не структура промпту — загостри прикметники до чогось конкретнішого для цього бренду перед перегенерацією.
- Щойно територія резонує, звужуй далі всередині неї, а не переходь одразу до роботи над логотипом — згенеруй ще 2-3 варіації в межах переможної території (інший матеріал, інша лайфстайл-сцена), щоб підтвердити, що напрямок тримається, перш ніж переходити до «Генератора напрямків концепції логотипу» (creative-and-visual, вже випущений) для реального дослідження знаку.
- Ці чотири території — стартова структура, не фіксована вимога — для бренду, де типографія чи патерн реально не релевантні категорії, заміни цю територію на інший кут (напр., територію макета упаковки), а не форсуй нерелевантну в набір.
