## Опис
Генерує кілька справді різних напрямків концепції логотипу з опису бренду — напрямок на основі wordmark, напрямок на основі символу/іконки й напрямок абстрактного знаку, кожен зі своїм промптом — замість одного промпту, чиї варіації всі приземляються на ту саму візуальну ідею з незначними відмінностями, оскільки ранній пошук логотипу потребує розмаху, не п'яти версій однієї концепції.

## Коли використовувати
- Починаєш пошук логотипу для бренду й хочеш розмах справді різних напрямків для реакції, не інкрементальні варіації на єдиній першій ідеї.
- Перша спроба генерації логотипу видала варіанти, що всі відчувались як та сама концепція з невеликими змінами, і потрібні промпти, структуровані так, щоб реально розходитись.
- Хочеш AI-згенеровані концепції логотипу як натхнення якості мудборду для людини-дизайнера, щоб розвинути далі — не фінальні, готові до продакшену файли логотипу (AI-генерація зображень не заміняє векторну роботу дизайну логотипу, особливо для того, що має масштабуватись, бути перевіреним на товарний знак і відтворюватись в один колір).

## Промпт

```
[ОСНОВА БРЕНДУ — повторно використовуй у всіх трьох напрямках]
{{BRAND_NAME}}, {{BRAND_ESSENCE}}, {{INDUSTRY_CONTEXT}}

[НАПРЯМОК 1 — На основі wordmark]
{{BRAND_NAME}} logo, wordmark-led design, {{BRAND_ESSENCE}}, custom typography, {{TYPOGRAPHY_STYLE}}, minimal, vector logo style, on plain white background --ar 1:1

[НАПРЯМОК 2 — На основі символу/іконки]
{{BRAND_NAME}} logo, symbol-led design, {{SYMBOL_CONCEPT}} icon paired with simple wordmark, {{BRAND_ESSENCE}}, minimal, vector logo style, on plain white background --ar 1:1

[НАПРЯМОК 3 — Абстрактний знак]
{{BRAND_NAME}} logo, abstract geometric mark, evokes {{ABSTRACT_QUALITY}}, {{BRAND_ESSENCE}}, minimal, vector logo style, on plain white background --ar 1:1
```

## Змінні
- `{{BRAND_NAME}}` — назва бренду/компанії, як вона має з'являтись чи на неї посилатись. Обов'язково.
- `{{BRAND_ESSENCE}}` — 2-4 прикметники, що фіксують реальну особистість бренду (напр., «надійний, точний, стриманий» проти «грайливий, сміливий, енергійний») — обов'язково, і це має справді диференціювати бренд, не за замовчуванням до загальних стартап-прикметників, що могли б описати будь-яку компанію.
- `{{INDUSTRY_CONTEXT}}` — чим займається компанія, оскільки це впливає на те, які візуальні метафори читаються як релевантні проти довільних. Обов'язково.
- `{{TYPOGRAPHY_STYLE}}` — для Напрямку 1: характер літерних форм (напр., «geometric sans-serif, tight letter spacing», «humanist serif with subtle warmth»). Обов'язково для цього напрямку.
- `{{SYMBOL_CONCEPT}}` — для Напрямку 2: конкретна візуальна концепція для іконки, ідеально щось конкретно пов'язане з {{INDUSTRY_CONTEXT}}, а не загальна абстрактна форма (напр., «a stylized compass needle» для навігаційного бренду, не просто «a swoosh»). Обов'язково для цього напрямку.
- `{{ABSTRACT_QUALITY}}` — для Напрямку 3: що має викликати абстрактний знак, не будучи буквальним (напр., «forward momentum», «interconnection», «stability») — цей напрямок призначений досліджувати відчуття, а не об'єкт. Обов'язково для цього напрямку.

## Приклад
**Вхід:** `{{BRAND_NAME}}` = «Meridian» · `{{BRAND_ESSENCE}}` = «точний, спокійний, надійний» · `{{INDUSTRY_CONTEXT}}` = «програмне забезпечення для фінансового планування для незалежних консультантів» · `{{TYPOGRAPHY_STYLE}}` = «геометричний sans-serif, щедрий міжлітерний інтервал» · `{{SYMBOL_CONCEPT}}` = «стилізована навігаційна лінія/дуга меридіана» · `{{ABSTRACT_QUALITY}}` = «стабільний рух вперед, тиха впевненість»

**Напрямок 1 — На основі wordmark:**
```
Meridian logo, wordmark-led design, precise, calm, trustworthy, custom typography, geometric sans-serif, generous letter spacing, minimal, vector logo style, on plain white background --ar 1:1
```

**Напрямок 2 — На основі символу:**
```
Meridian logo, symbol-led design, a stylized navigational line/meridian arc icon paired with simple wordmark, precise, calm, trustworthy, minimal, vector logo style, on plain white background --ar 1:1
```

**Напрямок 3 — Абстрактний знак:**
```
Meridian logo, abstract geometric mark, evokes steady forward direction, quiet confidence, precise, calm, trustworthy, minimal, vector logo style, on plain white background --ar 1:1
```

## Поради та варіації
- Розглядай кожен вивід цього промпту як натхнення стадії дослідження, не готовий логотип — прожени напрямок, що резонує, через реальний векторний дизайн-процес (дизайнером чи у векторному софті) потім; AI-згенероване растрове зображення непридатне для пошуку товарного знаку, немасштабоване нескінченно і часто має тонкі дефекти рендерингу, помітні лише в масштабі логотипу (нерівні товщини ліній, злегка асиметричні криві).
- Якщо жоден з трьох напрямків не відчувається правильним, це корисний сигнал про сам {{BRAND_ESSENCE}}, не лише про промпти — есенція бренду, що надто загальна (могла б стосуватись будь-якої компанії в {{INDUSTRY_CONTEXT}}), схильна давати незапам'ятовувані напрямки незалежно від того, яка з трьох структур використовується; загостри опис есенції перед повторною генерацією.
- Поєднуй з «Адаптером промпту переносу стилю» (creative-and-visual, вже випущений), коли напрямок обрано, якщо хочеш дослідити ту саму концепцію, відрендерену в кількох різних стилістичних обробках, перш ніж зупинитись на одній.
